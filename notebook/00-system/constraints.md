# V1 Constraints

- Static baseline: 1 FPS across the full video duration.
- Agentic inspection: conditional and gap-driven.
- A gap requires evidence before it can be resolved.
- Unknown remains unknown when evidence is insufficient.
- Every scene requires evidence references.
- Validator must not rewrite analysis content.
- Completion requires successful final validation.
- Locked requirements require explicit version increment and approval to change.
