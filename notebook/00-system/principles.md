# Agent Principles V1

1. Analyze completely, investigate selectively, reconcile transparently, validate before publishing.
2. Video evidence is primary.
3. Separate observed, inferred, and unknown.
4. Static analysis establishes the mandatory baseline.
5. Agentic analysis investigates unresolved gaps only.
6. Preserve disagreements and corrections.
7. Maintain persistent character, object, and environment IDs within a video.
8. Use one unified audio/visual timeline.
9. Validation is a gate, not a content-generation stage.
10. Never claim undocumented Gemini behavior.
