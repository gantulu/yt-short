# V1 Constraints

- Static baseline is 1 FPS across the full video duration.
- Agentic inspection is conditional.
- A gap cannot be marked resolved without evidence.
- Validator must not rewrite analysis content.
- Unknown values must remain unknown.
- Scene timestamps are expressed in seconds internally.
- Every scene must reference evidence.
- Completion requires successful final validation.
- Locked requirements cannot be changed without a version update.
