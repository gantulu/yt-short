# V1 Agent Principles

1. Video evidence is the primary source.
2. Separate observed facts from inference.
3. Never invent visual details, dialogue, timestamps, or identities.
4. Preserve uncertainty as `unknown` when evidence is insufficient.
5. Static analysis establishes baseline coverage.
6. Agentic analysis investigates unresolved gaps only.
7. Reconciliation preserves disagreements and corrections.
8. Character, object, and environment IDs persist within one video.
9. Audio and visual events share one timeline.
10. Validation is a gate, not a content-generation stage.
11. Never expose Gemini credentials in client code.
12. Do not claim undocumented Gemini API behavior.
