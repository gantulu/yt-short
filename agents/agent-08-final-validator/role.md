# Agent 08 — Final Scene Validator

Validation-only agent.

Checks:
- schema compliance
- unique scene IDs
- chronological timeline
- duration arithmetic
- overlaps
- unexplained gaps
- evidence references
- character continuity
- object continuity
- environment continuity
- audio/visual alignment
- unresolved reconciliation conflicts

The validator reports errors and warnings. It does not rewrite scenes or manufacture missing evidence.
