## Locked contract

The release implements:
1. Hybrid Static + Agentic.
2. Static 1 FPS full-duration baseline.
3. Conditional Agentic inspection of unresolved gaps.
4. Evidence reconciliation with corrections/conflicts preserved.
5. Persistent character/object/environment references.
6. Unified visual/audio timeline.
7. Conditional dedicated transcription.
8. Chronological scene decomposition.
9. Final validation gate.

No release change may silently alter these requirements.

## Runtime

Node.js 20+ is required.

```
npm install
npm test
npm run analyze -- <youtube-url-or-video-id>
```

Runtime Gemini credentials are supplied through environment variables and are not committed to the repository.

## Verification boundary

This release documentation records source-level release readiness. Live Gemini execution and `npm test` require an external Node.js runtime and valid Gemini credentials; they are not claimed as executed by this release preparation step.

## Release policy

Post-release changes must be versioned. Requirement changes require an explicit version increment and approval. Provider implementation changes are permitted only when they preserve the locked contract.
